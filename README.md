# EXPLODEATT：把 CAD 图块里的属性变成普通文字

这是一个给 AutoCAD 用的小工具，主要处理“带属性的图块”，特别是动态块。

## 用大白话说，它是干什么的？

有些 CAD 图块里面藏着型号、编号、参数等文字。这些文字不是普通文字，而是跟着图块一起工作的“属性”。

如果直接用 AutoCAD 自带的 `EXPLODE` 或 `X` 命令去炸开，常见结果是：文字内容不对、同一组文字重叠在一起、位置乱掉，或者根本不能正常变成普通文字。

EXPLODEATT 就是专门处理这种情况的。它会把图块里的属性内容读出来，生成可以单独编辑的普通文字，并尽量把文字大小和位置调整好。

你可以把它理解成：**把图块里的“隐藏文字”安全地释放出来。**

## 什么时候需要用它？

遇到下面情况时，可以试试这个工具：

- 动态块里有很多型号、规格、编号或参数；
- 直接炸开后，文字挤成一团；
- 炸开后出现错误的属性值；
- 想把图块里的文字拿出来单独修改；
- 后续还要把 CAD 文字导出成 CSV 或 Excel。

## 安装方法

不需要安装软件，只需要把 LSP 文件加载到 AutoCAD 中：

1. 打开 AutoCAD。
2. 在命令行输入 `APPLOAD`，按回车。
3. 找到本仓库里的 `plugins/EXPLODEATT-V6.LSP`。
4. 点击“加载”。加载成功后关闭窗口。

如果每次打开 AutoCAD 都要使用，可以在 APPLOAD 窗口的“启动组”里添加这个文件。

## 最简单的使用方法

1. 先保存一份图纸副本。
2. 输入 `EXPLODEATT`，按回车。
3. 用鼠标选择需要处理的图块。
4. 选择完后按回车。
5. 等命令行显示处理完成。
6. 放大检查生成的文字是否符合要求。

脚本也提供 `XATT` 命令，可以把它当作快捷入口使用。

## 处理大量图块时

如果一张图里有几百或几千个图块，可以一次框选多个图块。处理过程中不要反复点击 CAD，也不要强行关闭程序，等命令行出现完成提示后再继续操作。

## 使用后的结果

处理完成后，原来的属性内容会被转换成普通文字。普通文字可以像其他 CAD 文字一样移动、修改、复制，也方便后续用 MT2CSV 一类工具提取出来。

## 和 MT2CSV 配合使用

如果你的目标是把图块里的属性文字最终导出到 CSV 或 Excel，建议按下面的顺序操作：

1. 先用 `EXPLODEATT` 处理带属性的动态块，把里面的文字释放成普通文字。
2. 检查图面，确认文字没有重叠、内容没有明显错误。
3. 再加载并运行 MT2CSV。
4. 用鼠标选择刚刚生成的普通文字，按回车导出 CSV。

简单说就是：**EXPLODEATT 负责把图块里的文字释放出来，MT2CSV 负责把释放后的文字整理并导出。**

不过，普通的 TEXT/MTEXT 不需要先经过 EXPLODEATT，可以直接使用 MT2CSV。只有当文字藏在带属性的图块或动态块里，或者直接炸开会出现文字混乱时，才需要先使用 EXPLODEATT。

### 一个常见例子

图纸里有很多带“型号、规格、编号”的电气动态块：

- 只想在 CAD 里查看或修改：使用 EXPLODEATT；
- 想把这些内容导出到 Excel：先用 EXPLODEATT，再用 MT2CSV；
- 图纸里已经是普通文字：直接用 MT2CSV，不需要 EXPLODEATT。

## 常见问题

### 输入命令后提示找不到命令

说明 LSP 没有加载成功。重新输入 `APPLOAD`，确认选择的是 `EXPLODEATT-V6.LSP`，并观察命令行是否出现加载成功提示。

### 文字位置看起来不理想

不同图纸的块比例、字体和旋转角度可能不同。先撤销或关闭副本重新测试，再根据实际图纸调整结果。

### 能不能直接在原图上运行？

不建议。这个工具会修改图块属性并创建新的文字对象，最好先另存一份副本。
