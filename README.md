# EXPLODEATT for AutoCAD

EXPLODEATT 是一个 AutoCAD 辅助工具，专门处理带属性的图块，尤其是动态块。

## 它解决什么问题？

直接使用 AutoCAD 的 `EXPLODE` 或 `X` 命令处理带属性的动态块时，可能出现错误文字、属性挤在一起，或无法正常转换成普通文字。这个工具会读取图块里的属性值，生成普通文字，并调整位置和大小，方便继续编辑、排版或导出。

## 使用方法

1. 打开 AutoCAD，输入 `APPLOAD` 并回车。
2. 加载 `plugins/EXPLODEATT-V6.LSP`。
3. 输入 `EXPLODEATT` 并回车。
4. 选择需要处理的图块，选择完成后按回车。
5. 等命令行提示完成，检查生成的普通文字。

脚本还提供 `XATT` 作为快捷命令。

## 注意事项

- 使用前请先保存图纸，最好在副本上测试。
- 工具会修改图块属性并生成新的文字对象。
- 处理大量图块时，请等待命令行显示完成提示。
